2. ROLES TECNOLÓGICOS EN EL FRONTEND DEL PROYECTO RUEDA LIBRE

HTML (HyperText Markup Language)

Rol: Define la estructura y el contenido base de la página web.

Ejemplo concreto: Crear un menú de navegación superior con enlaces a "Inicio", "Modelos" y "Contacto" utilizando las etiquetas nav, ul y li.


CSS (Cascading Style Sheets)

Rol: Define los estilos visuales, las fuentes, los tamaños y la adaptabilidad del sitio web (diseño responsivo).

Ejemplo concreto: Aplicar un fondo verde ecológico, utilizar la tipografía Roboto, redondear los bordes de los botones y organizar el catálogo de bicicletas en columnas.


JavaScript

Ejemplo concreto: Crear un calculador interactivo en el que el usuario ingrese su altura y la página le muestre su talla ideal de bicicleta sin recargar la web.

10. IMPLEMENTACIÓN DE ESTILOS CSS

Primero busqué las fuentes en Google Fonts y elegí Montserrat para los títulos y Open Sans para los textos. Copié los tres enlaces proporcionados por Google Fonts y los agregué en la etiqueta head de las tres páginas HTML, antes del enlace a la hoja de estilos CSS.

Después creé la carpeta css y dentro de ella el archivo styles.css. Vinculé este archivo a las tres páginas del proyecto, teniendo en cuenta que las páginas ubicadas dentro de la carpeta paginas necesitan una ruta relativa diferente.

Dentro de styles.css utilicé :root para crear variables globales. Agregué las variables correspondientes a los cinco colores definidos en el mapa de colores del reto anterior, las dos familias tipográficas y tres tamaños de espaciado: S, M y L, expresados en rem.

Luego apliqué los estilos generales al body, incluyendo la familia tipográfica de los textos, el color principal y el fondo crema. También agrupé los encabezados h1, h2 y h3 para utilizar Montserrat, con un peso de fuente de 700.

Agregué estilos para los enlaces a, los botones button y el iframe del mapa de Google Maps. En los enlaces y botones utilicé los colores definidos en el mapa de colores, teniendo en cuenta el contraste entre el texto y el fondo.

También eliminé el estilo en línea que tenía el iframe del mapa y trasladé esa regla a la hoja de estilos externa, para mantener los estilos organizados en un solo archivo CSS.

Finalmente, utilicé las herramientas de desarrollador del navegador para revisar los estilos aplicados. Comprobé que los párrafos utilizaran Open Sans con peso 400 y que los encabezados utilizaran Montserrat con peso 700. También desactivé temporalmente la propiedad font-family de body y observé cómo cambiaba la fuente del párrafo, lo que me permitió comprobar la herencia de esa propiedad.

11. NAVEGACIÓN CON ESTADOS

Durante este reto trabajé los estados de los enlaces y los elementos del formulario mediante CSS. Agregué el identificador menu a la lista de navegación y la clase activo al enlace correspondiente a la página actual. También configuré los estados hover y focus para que los enlaces, botones y campos del formulario respondan al pasar el cursor y al navegar con el teclado.

Al aplicar los estilos, encontré un problema de especificidad: la regla #menu a prevalecía sobre .activo, por lo que el color definido en esta última aparecía tachado en las herramientas de desarrollador. Lo solucioné utilizando el selector #menu a.activo, que tiene mayor especificidad porque combina un identificador, un elemento y una clase. Así conseguí aplicar los estilos sin utilizar !important ni estilos en línea.

Finalmente, añadí un subrayado al enlace activo para identificar mejor la página actual y comprobé la navegación con Tab en las tres páginas, incluyendo los enlaces, botones y campos del formulario. Este ejercicio me permitió comprender mejor la cascada, la especificidad y la importancia de hacer que una página sea accesible mediante el teclado.

12. MODELO DE CAJA, TARJETAS, TABLAS, FORMULARIO Y MENÚ

Durante este reto trabajé el modelo de caja de CSS mediante la propiedad box-sizing: border-box, que permite incluir el padding y los bordes dentro del ancho total de los elementos. También establecí un ancho máximo para el contenido principal, centré el elemento main y definí una altura mínima para la portada utilizando unidades relativas al tamaño de la ventana.

Después, organicé los servicios de la página principal en tarjetas mediante Flexbox, agregando espaciado, bordes y bordes redondeados con las variables CSS definidas anteriormente. También mejoré la legibilidad de las tablas mediante border-collapse, padding, bordes y colores de fondo y texto con suficiente contraste en los encabezados.

En el formulario de reservas, utilicé display: block para organizar las etiquetas, width: 100% para ampliar los campos y :not() para excluir los botones de opción y las casillas de verificación de esa regla. Además, agregué separación entre los grupos mediante margin-bottom y ajusté el relleno del botón con padding.

Para organizar el menú de navegación en una fila, utilicé display: flex sobre el elemento #menu. También eliminé las viñetas con list-style: none y agregué espacio entre los enlaces mediante padding.

Finalmente, comparé el ancho de una tarjeta en las herramientas de desarrollador, en la pestaña Computed, modificando temporalmente box-sizing. Con border-box, el ancho registrado fue de 277.656 px; con content-box, fue de 225.656 px. Esta comparación me permitió observar cómo cambia el cálculo del ancho al modificar el modelo de caja.

Conclusión: este reto me permitió practicar el uso de Flexbox, las unidades relativas, las variables CSS, los selectores y el modelo de caja, además de comprender cómo mejorar la organización visual y la legibilidad de una página web.
